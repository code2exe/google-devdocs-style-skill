## [0.1.0] - 2026-08-18

Initial release.

### Added
- `SKILL.md` with reference hierarchy, ten core rules, document-type selection,
  voice and tone, and summaries of procedures and formatting.
- `references/procedures.md` — steps, sub-steps, component ordering within a step,
  multi-action steps, multiple paths, optional steps, location/goal/result ordering.
- `references/formatting.md` — text formatting, headings, lists, tables, notices,
  links, code in text, code samples, command-line syntax, placeholders, UI elements,
  numbers and dates and units, images, Markdown versus HTML.
- `references/language.md` — person, voice, tense, sentence structure, capitalization,
  abbreviations, pronouns, punctuation, reference-doc verbs, anthropomorphism,
  timeless documentation, excessive claims, third-party content.
- `references/word-list.md` — verified subset of the source word list, organized by
  category rather than alphabetically.
- `references/review-checklist.md` — eight-pass review workflow with severity grading.
- `examples/procedure-rewrite.md` and `examples/review-report.md`.
- `ACCURACY.md` recording verification status per source page.

### Fixed (before first release)
Corrections found by verifying an initial draft against the source word list, all
recorded in ACCURACY.md: `frontend`/`backend` compound forms, `file system`,
generic `CLI`, `repo`, the `please` exception, the `etc.` exception, `drop-down`,
and `comprise`. Removed invented entries not present in the source.
